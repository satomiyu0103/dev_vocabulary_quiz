【問題 13】基本の動詞・名詞

【結果】正解！

単語
mutable
コードもしくはプログラミングでの使われ方
リストや辞書など、代入で内容を変えられるオブジェクトを指す
コードでの例
items = [1, 2, 3] items.append(4) # OK: リストは mutable
