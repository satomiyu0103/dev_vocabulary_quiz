## 1. 背景と目的

### 1.1 背景

RPA_scripts・Data_Science の実装では、英単語・API 名・命名規則の理解がボトルネックになる。汎用の英単語アプリでは「自分のコード文脈」に即した復習が難しい。

2026 年に **開発語彙単語帳（dev-vocabulary）** を schema v2 で整備し、265 枚の JSON カードを `doc/life/career/dev-vocabulary/` に集約した。復習手段として当初は Gemini Gem（チャット採点）を試したが、採点の不安定さ・状態リセットにより学習 UX に耐えないと判断し、**ブラウザ上の JavaScript 採点**に切り替えた。

### 1.2 目的


| 目的          | 説明                                         |
| ----------- | ------------------------------------------ |
| **定着**      | 日常の意味とプログラミング上の意味をセットで覚え、コードを読む・書く速度を上げる   |
| **採点の確実性**  | LLM に依存せず、同じ選択で常に同じ正誤結果を返す                 |
| **手軽なアクセス** | 静的サイトとして Cloudflare Pages に公開し、URL から毎日開ける |
| **正本の分離**   | カード編集は Documents 秘書層、公開 UI は本プロジェクトに分離     |




### 1.3 対象ユーザー

- 本人（RPA / DS 開発の学習者）
- 就活・ポートフォリオ文脈で「実プロジェクト由来の語彙学習」を説明する際の参照先



### 1.4 スコープ


| 含む                        | 含まない           |
| ------------------------- | -------------- |
| `public/` のクイズ UI・統合 JSON | サーバ API・ユーザー認証 |
| Cloudflare Pages デプロイ     | カード編集 UI       |
| ローカルプレビュー・同期手順            | Gem 採点（一時停止）   |




### 1.5 学習運用（語彙正本側）

- 新規カード追加: **1 日 5〜15 枚**
- 復習ツール正本: ブラウザ 4 択（本プロジェクト）
- Gem: 一時停止（Gemini 安定後に再試行）
