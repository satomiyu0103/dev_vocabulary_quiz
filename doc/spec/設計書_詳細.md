## 2. モジュール構成（論理分割）

単一 HTML 内の関数群を次のモジュールに分割して理解する（ファイル分割は現行スコープ外）。

```text
QuizApp
  ├── DataLoader       … loadJson(), file input, startQuiz()
  ├── PoolManager      … filterCards(), refreshPool(), usedIds
  ├── QuestionEngine   … nextQuestion(), questionNum
  ├── ChoiceBuilder    … pickDistractors(), pickDistractorsJa() [目標], shuffle()
  ├── Scoring          … answer(), correctIndex 比較
  └── ExplainRenderer  … showFeedback(), appendExplainRow(), buildExampleList()
```


| モジュール           | 現行関数                                     | 責務                                         |
| --------------- | ---------------------------------------- | ------------------------------------------ |
| DataLoader      | `loadJson`, `startQuiz`, file input ハンドラ | JSON 取得・パース・クイズ開始                          |
| PoolManager     | `filterCards`, `refreshPool`             | モード別プール・枯渇リセット                             |
| QuestionEngine  | `nextQuestion`                           | 出題・UI 更新・選択肢生成の orchestration              |
| ChoiceBuilder   | `pickDistractors`, `shuffle`             | 誤答候補・シャッフル                                 |
| Scoring         | `answer`                                 | 正誤判定・ボタン無効化                                |
| ExplainRenderer | `showFeedback` 一式                        | 解説 DOM 構築（`createElement` / `textContent`） |

## 4. 日→英出題（現行 / ja2en）



### 4.1 処理フロー

```text
nextQuestion()
  answered = false
  feedback-panel を非表示、question-panel を表示
  refreshPool()
  if pool.length === 0 → 「カードがありません」
  current = pool[random]
  questionNum++
  distractors = pickDistractors(current, filterCards(allCards))
  choices = shuffle([current.term, ...distractors])
  correctIndex = choices.indexOf(current.term)
  UI: q-label, q-general, q-prog, choices ボタン生成
  updateStats()
```



### 4.2 pickDistractors（英単語誤答）

```text
terms = { current.term }
out = []
1. confusable_with[].term + related_terms から candidates に存在する語を最大 3 件
2. 不足時 shuffle(candidates) から term をランダム追加
3. まだ不足なら "—" でパディング
return out.slice(0, 3)
```



### 4.3 refreshPool

```text
pool = filterCards(allCards) で usedIds に無いカード
if pool.length === 0:
  usedIds.clear()
  pool = filterCards(allCards)   // 全問消化後リセット（FR-01）
```



### 4.4 採点（answer）

```text
if answered → return
answered = true
全 choice ボタン disabled
ok = (index === correctIndex)
選択肢に correct / wrong クラス
showFeedback(ok)
// usedIds 追加は showFeedback 内
```

## 5. 英→日出題（目標 / en2ja）— 未実装



### 5.1 出題ルール


| 項目    | 仕様                                                                                 |
| ----- | ---------------------------------------------------------------------------------- |
| 問題文   | `#q-term` に `current.term` を表示。`#q-general` / `#q-prog` は非表示                       |
| 正解種別  | `meaningKind = random(["general", "programming"])`                                 |
| 正解文字列 | `meaningKind === "general"` → `meaning_general_ja`、それ以外 → `meaning_programming_ja` |
| 誤答    | `pickDistractorsJa(current, candidates, meaningKind)`                              |




### 5.2 pickDistractorsJa（目標）

```text
correctText = 正解の日本語意味
texts = Set([correctText])
out = []
1. candidates から同 meaningKind の他カードの意味を収集（空はスキップ）
2. confusable_with の term に一致するカードの同種意味を優先
3. 不足時プールからランダム
4. 3 件未満は "—" パディング
choices = shuffle([correctText, ...out.slice(0,3)])
correctIndex = choices.indexOf(correctText)
```



### 5.3 mixed モード

`nextQuestion` 冒頭で:

```text
if questionDirection === "mixed":
  effectiveDirection = random(["ja2en", "en2ja"])
else:
  effectiveDirection = questionDirection
```

以降は `effectiveDirection` に応じて §4 または §5.1 の分岐。

## 8. ExplainRenderer 仕様

NFR-31 に従い、解説は `createElement` + `textContent`。コード例のみ `<code>` に `textContent` で snippet を設定。

表示順:

1. 単語（`strong`）
2. 日常の意味
3. プログラミングでの意味
4. コードもしくはプログラミングでの使われ方（`usage_note_ja`）
5. 日常英語の例文（`ul.examples`、最大 2 件）
6. コードでの例（`code` + **目標**: `note_ja` を DD に追加）

**目標改善（FR-13）**: `examples_code[0].note_ja` をコードブロック直下に表示。
