## 1. 目的と範囲

### 1.1 目的

[要件定義書.md](要件定義書.md) の FR / NFR / CR を、**実行可能なテストケース**に落とし込み、リリース前に検証する。ケース数は **直交表（L9）** と **ペアワイズ法** で代表抽出し、全組合せ爆発を避ける。

### 1.2 スコープ

| 含む | 含まない |
|---|---|
| 手動 UI テスト、データ検証設計 | Playwright 実装（任意・将来） |
| FR-04/05（英→日）のテスト定義 | 英→日実装（`pending_impl` まで） |
| コンテンツサンプルレビュー手順 | 全 265 語の目視（サンプル 10 語/モード） |

### 1.3 手法の使い分け

| 手法 | 適用対象 | 理由 |
|---|---|---|
| **ペアワイズ法** | ブラウザ×ビューポート×ネットワーク×JSON 読込 | 環境因子の偶発相互作用を少ケースでカバー |
| **直交表 L9** | モード×出題方向×回答結果×プール状態 | 機能状態の 3 水準因子を 9 ケースに圧縮 |
| **固定テスト** | 回帰必須・単因子・受け入れ基準 | 直交で落ちる境界を補完 |
| **RTM** | 全要件 ID | 要件定義の検証漏れ防止 |
